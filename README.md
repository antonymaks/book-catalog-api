# Book Catalog API

Учебный проект каталога книг на языке Go.

## Цель проекта

Разработка WEB-приложения для сравнения принципов построения REST API и GraphQL API.

## Технологии

- Go
- REST API
- GraphQL
- PostgreSQL
- MongoDB
- HTML/CSS/JavaScript
- Docker
- Git

## Основные возможности

- просмотр каталога книг;
- поиск и фильтрация книг;
- добавление, редактирование и удаление книг;
- работа с авторами;
- пользовательские списки чтения;
- разграничение прав пользователей;
- взаимодействие через REST API;
- взаимодействие через GraphQL API.
